# System Anomaly Detection Using Machine Learning

An unsupervised machine learning project designed to identify unusual patterns in system performance metrics using Python and the Isolation Forest algorithm.

## Project Overview

System performance monitoring is essential for maintaining reliable applications and infrastructure. Unexpected spikes in CPU utilization, memory consumption, or network activity can indicate potential performance issues.

This project explores how machine learning can help identify anomalous system behavior by analyzing performance metrics and flagging unusual observations.

The goal is to demonstrate how unsupervised learning can support proactive system monitoring and anomaly investigation.

## Technologies Used

- **Python** — Data processing and machine learning implementation
- **Scikit-learn** — Isolation Forest anomaly detection
- **Pandas** — Data manipulation and analysis
- **NumPy** — Numerical computations
- **Matplotlib** — Data visualization

## Key Features

- Analyze CPU utilization, memory usage, and network activity.
- Apply unsupervised machine learning to identify unusual system behavior.
- Generate anomaly predictions using Isolation Forest.
- Explore patterns in system performance metrics.
- Visualize normal and anomalous observations.

## Machine Learning Approach

### Isolation Forest

Isolation Forest is an unsupervised machine learning algorithm designed to detect anomalies by isolating observations through randomly generated decision trees.

Unlike supervised learning algorithms, Isolation Forest does not require labeled examples of system failures.
